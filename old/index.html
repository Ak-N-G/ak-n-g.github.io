How I reason through bottlenecks, system latency, and edge compute trade-offs.

SYSTEM DESIGN · EDGE DSP

Sub-Millisecond PPG Signal Processing: Eliminating Motion Artifacts via POS/CHROM & Adaptive Kalman Filtering

Extracting blood volumetric changes from standard RGB CMOS phone cameras introduces severe motion noise, uneven sensor exposure, and non-linear lighting shifts. The core challenge: maintaining sub-bpm accuracy while processing 60 FPS video streams on resource-constrained mobile CPUs without causing thermal throttling or dropping camera frames.

[CameraX 60 FPS RAW YUV] ↓ Zero-copy frame lock [Facial ROI Spatial Downsampling] → 120x120px skin cluster ↓ POS (Plane-Orthogonal-to-Skin) & CHROM algorithms [BVP Waveform Extraction] → Dynamic range normalized ↓ 2nd-order Butterworth (0.75–3.0 Hz) + Kalman Filter [LiteRT Peak Inversion Engine] → HR, SpO&sub2;, HRV, Stress @ 60 FPS
  • Zero-Copy Memory Buffer: Directly queried Android hardware ImageProxy planes via native C++ buffers, avoiding RGB raster conversion overhead and saving ~14ms per frame.
  • Motion Robustness: Projected RGB color signals onto a plane orthogonal to the skin tone vector (POS), isolating genuine pulse-induced capillary volume changes from ambient flicker.
  • Compute Efficiency: Replaced heavy 3D ConvNets with lightweight temporal DSP filters + a quantized 1.2MB LiteRT model, preserving 60 FPS on sub-$150 Android devices.
SYSTEMS ENGINEERING · HEADLESS LINUX

Autonomous Daemon Healing: Building Zero-Root Telemetry & Remote Tunnels under Mobile Linux

Running persistent automation on mobile Linux (Termux) without root privileges faces aggressive Android battery killers (Doze mode, Phantom Process Killer, and OOM-killer). This architecture constructs a crash-resilient watchdog engine that maintains reverse SSH tunnels, dynamically binds network sockets, and streams hardware telemetry.

[Android Boot Receiver (Termux:Boot)] ↓ Spawn daemon with flock mutex [Supervisor Daemon (POSIX Shell)] ↔ SIGTERM / SIGHUP Trapped ↓ Periodic heartbeat (10s ring buffer) [Tunnel State Inspector] → Socket probe (netstat / /proc/net/tcp) ↓ Failure detected? Tear down & exponential backoff [Autossh Reverse Tunnel + Telegram Dispatcher] → 99.9% Remote Node Uptime
  • PID Lock & Orphan Reaping: Enforced single-instance execution via Linux kernel flock descriptors and automated cleanup of zombie child processes.
  • Self-Healing Tunnel Logic: Monitored TCP keepalive roundtrips instead of relying solely on process state, triggering reconnects immediately upon carrier IP rotation.
  • Proactive Telemetry: Compressed rolling system logs (RAM buffers, vnstat network bandwidth, and device temperature) and dispatched asynchronous Telegram webhooks during security anomalies.
